1. Formulación del Algoritmo del Índice de Capacidad de Acogida (ICA)

Para evitar distorsiones por el tamaño poblacional entre municipios rurales y semiurbanos, todas las variables se normalizan en indicadores per cápita y se escalan a un rango de 0 a 100 aplicando Winsorización previa ($p_5$ - $p_{95}$):

ICA = 0.30 × Vivienda + 0.30 × ( (Sanidad + Educación) / 2 ) + 0.25 × Conectividad + 0.15 × Holgura
Dimensión Ponderación Variables Analizadas Criterio de Saturación
Vivienda y Suelo 30% Precio compra (€/m²), alquiler (€/m²), viviendas vacías y suelo vacante. Stock de vivienda vacía movilizable + edificabilidad residencial en suelo urbano.
Sanidad Pública 15% (media) Médicos de Familia por 1.000 hab., consultorios y camas hospitalarias. Límite máximo regulatorio de 1.500 habitantes por médico de AP.
Educación Pública 15% (media) Plazas escolares autorizadas, alumnos matriculados y ratio de ocupación. Umbral de saturación en el 95% del aforo escolar (17% pob. escolar).
Conectividad y Movilidad 25% Tiempo a Madrid (Sol), paradas interurbanas (CRTM) y cobertura fibra (FTTH). Tiempos > 60 min y falta de banda ancha penalizan fuertemente el score.
Capacidad Ociosa / Holgura 15% Población absorbible sin saturar ningún servicio / Población actual. Premia municipios con margen disponible proporcional a su tamaño actual.

3. Ecosistema Tecnológico Oracle Implementado

ARQUITECTURA CLOUD-NATIVE DE ORACLE: En estricto cumplimiento de las recomendaciones del bloque técnico del Datathon (Andrés Araújo y Óscar Sánchez), el proyecto se basa en:

  • Oracle Database 19c / 21c / 23ai: Motor relacional con 5 tablas, columnas virtuales calculadas en motor e índices semánticos y espaciales.
  • Librería Oficial python-oracledb (Modo Thin): Conector nativo en Python sin librerías C externas, con soporte para Oracle Cloud Autonomous Database mediante Wallet TLS.
  • Oracle APEX (Universal Theme): Cuadro de mando ejecutivo interactivo con Mapas SVG, tarjetas de KPIs y simulador en tiempo real.
